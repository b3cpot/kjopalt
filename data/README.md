# Spillkatalog

`games.json` er bygget fra åpne kilder på GitHub:

- Spillister: [libretro-database](https://github.com/libretro/libretro-database) (No-Intro og Redump)
- Boksbilder: [libretro-thumbnails](https://github.com/libretro-thumbnails)

Bygg på nytt: kjør `build.py` (se `systems.py` for hvilke konsoller som er med).
Felt: `s` = konsoll, `t` = tittel, `r` = region, `p` = bilde-repo, `f` = filnavn på boksbildet.
