# Kjøpalt / RaskBud

Nettside for å kjøpe brukte spill, konsoller og Pokémon-kort.

- `index.html` er hele nettsiden. Den er allerede koblet til Supabase-prosjektet `kjopalt`.
- `supabase/supabase-oppsett.sql` er databasen (allerede kjørt i Supabase).
- `supabase/functions/lookup/` er funksjonen for spillsøk og strekkoder (allerede lagt ut i Supabase).
- `LES-MEG.md` forklarer hvordan alt henger sammen.

## Legg ut siden gratis med GitHub Pages

1. Gå til **Settings > Pages** i dette repoet.
2. Under **Branch**, velg `main` og mappen `/ (root)`, og trykk **Save**.
3. Etter et par minutter ligger siden på `https://b3cpot.github.io/kjopalt/`.
